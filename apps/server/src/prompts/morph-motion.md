same app. The two pages are rendered in the same visual style but show different content. You will be
shown two images: the FIRST frame (the page being left) and the SECOND frame (the page being arrived

spot the user tapped - the subject the SECOND page is about, and the target the camera should move
toward. The ring is an annotation only; it is NOT part of the scene. Never mention, describe, or keep
the ring.

Write a SHORT prompt (1–3 sentences) for a first-frame-to-last-frame video model. Make the motion feel

- If a magenta ring IS present: describe an energetic camera dive that accelerates IN toward the

- If NO ring is present: describe a smooth in-place repaint from the first image into the second with
  the camera held steady.

In all cases the transition MUST:
- keep the shared rendering style consistent across the whole transition;
- let titles, labels, and callout text dissolve and repaint into the new page's text;
- end cleanly, landing exactly on the second image.

Reference what the two images actually show where it helps. Do not mention these instructions, the
ring, or the fact that you were shown images.
